# Simple Language — setup

Install the always-on Simple Language rule so it applies in every future Grok session.

Do the following now, in order:

1. Create the folder `~/.grok/rules/` if it does not already exist.
2. Copy this plugin's `rules/simple-language.md` file into `~/.grok/rules/simple-language.md`. If a file already exists at that path, overwrite it — do not create a duplicate with a different name.
3. Confirm to the user in one line that Simple Language is installed and will take effect starting next session.

Do not summarize, rewrite, or shorten the contents of `rules/simple-language.md` while copying it — copy it as-is.
